# Agile Legacy Hero

## Eigen repository maken

Maak eerst een eigen repository vanuit deze template. Werk daarna alleen in je eigen repository.

1. Open deze repository op GitHub.
2. Klik op **Use this template**.
3. Kies **Create a new repository**.
4. Geef je repository een herkenbare naam.
5. Kies **Private**, tenzij anders afgesproken.
6. Klik op **Create repository**.

## Docenten toegang geven

Voeg na het aanmaken van je eigen repository de volgende GitHub-gebruikers toe als collaborator:

Voor app:
- `markvanmeerten`
- `grifa12`

Dit doe je in je eigen repository via:

```text
Settings > Collaborators > Add people
```

## Werken aan de opdracht
Clone je eigen repository naar je computer en werk daarin verder.

Gebruik de map die bij jouw opdracht hoort:

- documentatie/ voor de opdracht en bijlagen
- web/ voor de PHP-website
- app/ voor de C#-applicatie en ASP.NET website
